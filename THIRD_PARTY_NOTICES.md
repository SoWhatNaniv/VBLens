intrinsic classes) and `src/core/data/msvbvm.json` (MSVBVM50/60 export ordinals → names)

## ActiveX control type information
`src/core/data/ocxlib.json` lists the class, member and event names, GUIDs, DISPIDs and
vtable offsets of the ActiveX controls that shipped with Visual Basic 5/6 (MSCOMCTL,
COMCTL32, MSWINSCK, MSINET, COMDLG32, RICHTX32 and others). It was generated by
`tools/gen-ocxlib.ts` from the controls' type libraries. It holds interface descriptions only,
and no code or binaries from those files. The controls are Microsoft products.
